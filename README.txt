公開する例（GitHub Pages）:
1. GitHubで新しい公開リポジトリを作成
2. このZIPを解凍し、muse_pwa_v6フォルダ内の5ファイルをリポジトリのルートにアップロード
3. Settings → Pages → Deploy from a branch → main / root を選び保存
4. 表示された https://...github.io/.../ のURLをiPhoneのSafariで開く
5. Safariの共有メニューから「ホーム画面に追加」を選ぶ
